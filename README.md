# Haprial Android

Haprial 博客管理 Android App — Kotlin + Jetpack Compose + Markwon

## 功能

- 📝 文章管理（列表/搜索/发布/下架/删除）
- ✍️ Markdown 编辑器（Markwon 实时渲染）
- 💬 评论管理（查看/回复/置顶/删除）
- 🖼️ 图片管理（浏览/上传/复制/移动/删除）
- 🔗 友链管理
- ⚙️ 设置（统计/退出登录）

## 技术栈

- Kotlin + Jetpack Compose
- Material Design 3
- Markwon (Markdown 渲染)
- Retrofit + OkHttp (网络)
- Room (本地缓存)
- Koin (依赖注入)
- Coil (图片加载)

## 构建

GitHub Actions 自动编译，push 到 main 分支即可。
